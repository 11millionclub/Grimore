# GriMore

*Your world of stories.* A mobile-first literary social app built with Expo and Supabase.

The app lives in [`grimore/`](grimore/). Start with [`grimore/README.md`](grimore/README.md) for setup, architecture, the database and testing.

```bash
cd grimore
npm install
cp .env.example .env   # add your Supabase anon key
npx expo start
```
